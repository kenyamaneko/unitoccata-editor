# 用語集

| 日本語           | コードで使う語           | 定義                                                                                 |
| ---------------- | ------------------------ | ------------------------------------------------------------------------------------ |
| tick             | `tick`                   | 時刻の単位。4分音符を 960 tick とする                                                |
| レーン           | `lane`                   | ノーツを置く縦の列。0 始まりの整数                                                   |
| 位置             | `ChartPoint`             | tick とレーンの組。譜面上の点の位置を表す                                            |
| タップノーツ     | `tap`                    | 1点を押すノーツ                                                                      |
| フリックノーツ   | `flick`                  | 指定方向へ弾くノーツ。方向は上・左・右                                               |
| ロングノーツ     | `long`                   | 先頭の点と、それに続く点の並びで表すノーツ                                           |
| 終端             | `end`                    | ロングノーツの最後の点。離すか、指定方向へ弾くかを持つ                               |
| 終端フリック     | `end` の `kind: 'flick'` | ロングノーツの終端を、指定方向へ弾く操作                                             |
| チェックポイント | -                        | ロングノーツの始点と終端の間にある点                                                 |
| プロジェクト     | -                        | 曲ごとにクラウドで管理する単位。音源、プロジェクト情報、その下の譜面をまとめる       |
| プロジェクト情報 | `projectInfo`            | 曲名・オフセット・小節数・テンポ・拍子をまとめた、プロジェクトの全難易度で共通の情報 |
| 譜面設定         | -                        | 譜面名とレーン数。譜面ごとに持つ                                                     |
| 譜面名           | `chartName`              | 譜面の名前。書き出す譜面ファイルの名前とクラウドの保存に使う                         |
| オフセット       | `offsetMs`               | 音源の再生開始から tick 0 までの時間 (ミリ秒)                                        |
| テンポ変化点     | `TempoChange`            | BPM が変わる tick と BPM の組                                                        |
| 拍子変化点       | `SignatureChange`        | 拍子が変わる tick と分子・分母の組                                                   |
| 拍               | `beat`                   | 小節を区切る単位。拍子の分母が表す音符の長さを 1 拍とする                            |
| 小節番号         | `barNumber`              | 拍が何小節目にあるかを表す番号。1 始まり                                             |
| グリッド分割     | `gridDivision`           | ノーツが吸着する間隔を、何分音符かで表した値                                         |
| 譜面             | `chart`                  | 1 難易度分のノーツの集まり                                                           |
| 判定ライン       | `judgeLine`              | プレビューの画面で、ノーツが流れてくる線                                             |
| プレビュー       | `preview`                | 曲に合わせて、ノーツが判定ラインへ流れる画面                                         |
| スクロール位置   | `scrollTick`             | エディタのタイムラインの下端にある tick                                              |
| 再生位置         | `previewTick`            | プレビューの画面が覚えている tick                                                    |
| 小節数           | `barCount`               | 譜面の長さを決める、小節の数                                                         |
| ベロシティ       | `velocity`               | MIDI のノートオンに付く 0〜127 の値                                                  |
| 音程             | `pitch`                  | MIDI のノートの高さ。音名で書く                                                      |
| 分解能           | `ticksPerQuarter`        | MIDI ファイルが持つ、4 分音符 1 つあたりの MIDI の tick 数                           |
| 音源             | `audio`                  | 曲の音声ファイル                                                                     |
| 曲名             | `songName`               | プロジェクトの名前。書き出す譜面ファイルの名前とクラウドの保存に使う                 |
